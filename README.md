# MolinaGo - Aplicativo de Locação de Veículos

MolinaGo é um aplicativo que oferece diversas opções de veículos para locação, incluindo bicicletas elétricas, patinetes, jet skis e carros elétricos de luxo. Ideal para quem busca mobilidade prática, sustentável e cheia de estilo.

## 🚲 Veículos Disponíveis
- **Bicicleta Elétrica Sport**: Ideal para passeios urbanos com autonomia de até 40km.
- **Patinete Elétrico Pro**: Velocidade máxima de 25km/h com design moderno.
- **Jet Ski Performance**: Potente e perfeito para aventuras aquáticas.
- **Carro Elétrico Premium**: Luxuoso e focado em uma experiência de condução única.
